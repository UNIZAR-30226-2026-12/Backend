# Módulo: Users (Perfil de Usuario)

**Responsabilidad:**
Manejo de los datos del usuario autenticado. Permite consultar y actualizar el perfil básico (email, username) y las personalizaciones estéticas.

**Funcionalidades:**
- Configuración de colores preferidos de tablero y fichas.
- Consulta de estadísticas básicas de perfil.
