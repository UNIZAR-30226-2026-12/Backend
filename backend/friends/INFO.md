# Módulo: Friends (Sistema Social)

**Responsabilidad:**
Lógica de relaciones entre usuarios. 

**Funcionalidades:**
- Envío, aceptación y rechazo de solicitudes de amistad.
- Control de spam: gestión de la tabla `friend_request_rejections` para bloquear a usuarios tras 3 rechazos.
- Eliminación de amigos.
